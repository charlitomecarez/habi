## Milestone 0 findings

| Item              | Result                                                                                                                                                                                                                                                                                                |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Statement import  | Cause found in the Expo source: its `fetch` throws on the `{ uri }` form part before any request leaves the phone, so every bank fails on Android and the logs stay empty. The 546 guess in the plan was wrong. The sample parses, and the totals match. Milestone 5 fixes it. Not tested on the A56. |
| Live function     | `import-statement` boots and answers. A cold start takes 6 to 8 seconds, and a warm reply takes about 1 second.                                                                                                                                                                                       |
| Play audio        | Charli confirmed that audio plays. Milestone 6 needs only the visible player states.                                                                                                                                                                                                                  |
| Health Connect    | Charli confirmed it.                                                                                                                                                                                                                                                                                  |
| Backup            | A dump is 668 KB, so 30 days fit the 500 MB limit. The first run restored into an empty Postgres, and all 51 `public` tables matched. It uses the database password, not a read-only role.                                                                                                            |
| football-data.org | The free plan gives 10 calls a minute, the five leagues and league tables. Scores are delayed. The site has no terms page that I could read, and Charli chose to use it anyway for this private app.                                                                                                  |
| balldontlie       | The free plan gives 5 calls a minute, with teams and games. Standings are paid, so the app calculates them. The terms allow storing data for a private app.                                                                                                                                           |
| Sports keys       | `FOOTBALL_DATA_KEY` and `BALLDONTLIE_KEY` are set as Edge Function secrets. Neither is tested, because the first call comes in milestone 15. The balldontlie signing secret is for webhooks, and the app does not need it.                                                                            |
| freehire          | The filter is `countries=PH`. The docs say 600 calls a minute, and the live header says 120. One daily run needs only a few calls. An unknown filter is ignored, so `job-search` must check `meta.ignored_params`.                                                                                    |
| Job quality       | 99 results for project manager and software developer in the Philippines: 0 closed, 5 repeats, median age 21 days, all `https`. 56 links opened and 2 were dead. 38 JobStreet links refused the check, so they need a phone test.                                                                     |
