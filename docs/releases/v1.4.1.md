## Release notes

This text is a copy of the GitHub release.

This patch release renames the app to Habi and prepares the repo to become public.

- **Name:** The app is now called Habi, Tagalog for "weave". The package and the link scheme stay the same, so the new APK installs over the old one.
- **Backup:** The daily encrypted database backup runs in a separate private repo. Its run logs and files stay private.
- **Docs:** The docs use general terms instead of personal details.
