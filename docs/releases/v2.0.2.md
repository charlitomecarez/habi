## Concerns

The owner found these problems on the phone with the v2.0.1 APK:

- Module screens do not scroll up or down.
- After the first fix, the owner found that module screens still do not scroll on the web, for example `/news`.
- The Schibsted Grotesk font is gone.
- The weave on Home looks wrong: the pattern stops early, and the stitch strip is only a sliver.
- Todo rows have a thin magenta frame.

## Causes and fixes

| Concern                   | Cause                                                                                                                                                                                                                                                 | Fix                                                                                                                                                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| No scroll                 | expo-router 58 gives the drag back `minOffsetX` and `maxDeltaY`. Gesture handler 3.3 does not read them. The drag back covers the full width, so it took every swipe, also up and down.                                                               | `patches/expo-router+58.0.29.patch` uses `activeOffsetX` and `failOffsetY`. `patch-package` applies it in `postinstall`. This needs a new APK.                                                                                 |
| No scroll on the web      | On the web, the JS stack gives a card that fills the window `min-height: 100%` and lets it grow with its content, so the page scrolls instead of the list. The Expo web page does not scroll its body, so nothing scrolls.                            | `lib/transitions.web.ts` sets `cardStyle: { flex: 1 }`, so the card keeps the window height. Claude checked `/`, `/todos`, `/more`, `/news`, `/habits`, `/shopping` and `/money/transactions` in a browser: each list scrolls. |
| No font                   | v2.0.1 put the font files in the APK assets. `font-bold` also sets weight 700, and Android then looks for a `_bold` file that does not exist and uses Roboto.                                                                                         | `app.json` registers each font as an Android font family with its true weight. This needs a new APK.                                                                                                                           |
| Weave and stitch          | The weave and the stitch strip drew their SVG at "100%". On Android, `react-native-svg` keeps the first size and does not redraw when the parent grows.                                                                                               | `WeaveField` measures each view and gives the SVG its size in px. The stitch SVG is full width, and the animation only clips it.                                                                                               |
| Magenta frame on rows     | The Done and Delete buttons sit behind each row. On Android their edges showed around the row.                                                                                                                                                        | `SwipeRow` hides the buttons while the row is closed.                                                                                                                                                                          |
| "Open content Planning"   | Claude found this on the Home screenshot. The Home link lowercased the first letter of any title that starts with a capital and a small letter.                                                                                                       | Only a title with one capital starts in lower case.                                                                                                                                                                            |
| React warnings on the web | Claude found these in the browser console. `ModuleHeader`, `Skeleton` and `SplashHandover` put the Android-only hiding props on a Reanimated view, and `EmptyState` and `UlamPicture` put them on an SVG. On the web, both hand the props to the DOM. | The props move to a plain `View` around the same content. Claude checked seven routes in a browser: no console errors.                                                                                                         |
