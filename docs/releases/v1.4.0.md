## Release notes

v1.4.0 adds News, sleep from the screen, every app in Screen time, skeleton loading, and a vault PIN and recovery key. It also has four fixes. The app was still called my-app in this version.

### Fixes

- **Keyboard:** every screen with a text field handles the keyboard, and a test fails when a new screen forgets it. Lists keep a gap at the screen edge.
- **Find a work:** Groq ranks 5 jobs at a time, waits and tries again. Jobs it cannot rank save as "Not ranked". The new `job-search` function goes live after the v1.4.0 APK is installed.
- **Sports:** all NBA games and the standings show team logos.
- **Banig:** every delete asks in one sheet, the Save bars have 2 px rules, and first-run screens use the empty state.

### New features

- **News:** headlines from seven outlets, Philippines first, with images, a story page and an in-app browser.
- **Sleep:** the app finds last night's sleep from when the screen was off, with no prompt. It stays on the phone.
- **Screen time:** a screen lists every app, today and this week.
- **Loading:** screens show a skeleton in their shape, not a spinner.
- **Home:** the photo is back, with the games of up to 12 followed teams and three headlines.
- **Vault:** a 6-digit PIN, a recovery key with an email code, and a change of master password.
- **Modules:** Settings › Modules hides modules. A module with no server key hides by itself.
- **Tabs:** a tap on a tab slides to it.
- **Email:** the digest uses the Banig look. The six sign-in emails use it after the templates are pasted in the Supabase dashboard.

### The repo

- The MIT licence, a setup guide and a new README. gitleaks found no secret in the history. The repo stays private.

### Platform notes

- The APK comes from Build from GitHub in expo.dev, and it is not on the GitHub release. Install it over v1.3.0.
- The APK has new native code and `expo-web-browser`, so an update over the air cannot replace it.
- Do not change or recover the master password on v1.3.0. Version 2 of the vault opens only on v1.4.0.
- The seven migrations and the `news-sync`, `sports-sync`, `send-reminders` and `app-features` functions are already live.
