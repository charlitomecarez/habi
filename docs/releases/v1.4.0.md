## Development status

Code for milestones 0 to 13 is written on stacked branches, and `r/v1.4.0` holds all of it. Type check, lint and 301 tests pass.

### Live (Nov 8, 2026)

- A fresh database backup ran first (Actions run 42451366012, success).
- The 4 migrations are applied. `npm run db:types` matches the hand-edited types with no diff.
- `sports-sync`, `news-sync` and `send-reminders` are deployed. `news-sync` needed its own `deno.json`, added in the fix.
- First runs: News saved 135 stories from all 7 feeds, with no feed failing. All 241 NBA games and the NBA standings have logos. The `news-sync` cron job is scheduled.
- The licence is MIT (`LICENSE`).
- Design revision 2 (story page) is built. Migration `20261108000400_news_summary` is applied, `news-sync` is redeployed, and 134 of 138 stories have a summary. `expo-web-browser` is new, so it needs the v1.4.0 APK.

### What moved from the handoff

- Milestone 1: the vault unlock gate already had keyboard handling. The new test found the alarm sums field instead, so that got the fix.
- Milestone 3: sync only reaches 21 days back, so a data-only migration backfills the older NBA rows.
- Milestone 5: the native function is `getScreenEvents`, and the night rule in `lib/sleep-detect.ts` builds the dark spans from it.
- Milestone 6: the edit and detail screens that centred a spinner also got a skeleton, so no full-screen spinner is left. Three small spinners stay: statement reading, place search and the quick unlock switch.
- Milestone 7: the delete confirm is a new shared `ConfirmSheet`. `DataRow` also gained `chevron`.
- Milestone 8: design revision 2 added a story page with the feed's summary, and the full story in an in-app browser.
- Milestone 8: Inquirer uses `/fullfeed`, because its news feed labels Philippine time as UTC.
- Milestone 11: there were no digest tests, so a local render checked the HTML at 360 px instead.
- Milestone 12: gitleaks found no secret in 132 commits. The owner's email is only in commit author lines, not in any file.

### Impeccable

`/impeccable audit` ran from source on the new and changed screens (Android, no rendered app). It found two loading skeletons with no side padding (Vehicle, Journal entry), now fixed. `critique` and `polish` need rendered screens, so they wait for the APK.

### Not tested yet

Every phone check in the handoff: keyboard on the eight screens, sleep after a real night, screen time totals against Digital Wellbeing, skeletons on slow data, the delete sheets, News and its images, Home games and photo, the tab slide, and the emails in Gmail.
