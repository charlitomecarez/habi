## Concerns

- Smooth motion across the app: screen transitions, sliders and sheets, with Telegram as the model for the motion only.
- A quieter layout that keeps the Banig brand, with the style of the `habi-site` landing page.
- The login screen is plain, and it shows a grid icon, not the real Habi mark.
- Error notices show the raw Supabase message, which people cannot understand. Added during Design as milestone 7.

The v1.6.1 plan, for the login screen only, became part of this release before any work started: [Habi v1.6.1 plan](https://claude.ai/artifact/WFvnRm6iXEPHaFnAbGKuCA).
