## Concerns

- Smooth motion across the app: screen transitions, sliders and sheets, with Telegram as the model for the motion only.

## Release notes

This text is a copy of the GitHub release.

v2.0.0 is the redesign: smooth motion with the Banig look kept, a new login and Habi mark, and error messages in plain words. Install the v2.0.0 APK for the new icon and splash.

### Motion and navigation

- **Timings:** every move uses the timings in `lib/motion.ts` and one easing. Reduce motion turns each move into a short fade.
- **Screens and forms:** a screen slides in from the right, and a right drag from anywhere goes back. Full-screen forms rise, and a drag down from the top closes them.
- **Unsaved changes:** a form with changes asks "Discard your changes?" before it closes.
- **Tabs and sheets:** the cream pill glides to the open tab. A sheet rises on a spring and closes on a drag down.

### The look

- **Login:** indigo with the banig weave, the Habi mark and one line about the app.
- **App icon:** the launcher icon, the themed icon, the splash and the browser icon show the gold-tile mark.
- **Home:** the top sits on the weave, with the amount in gold and a stitch strip.
- **Modules:** every list and detail screen has a large cream title beside the module icon. More is one list with section tints and counts.

### Lists and errors

- **Swipe rows:** swipe a todo for Done and Delete, with 5 seconds to undo. Habits swipe to Done, and shopping items to Bought.
- **Errors:** plain sentences that say what happened and what to do, never the server text. Only the admin sees the error code.

### What moved

- Back after a save, short lists that jump to the top, the small tab numbers, the cut-off labels and the E2E failure moved to v2.0.1.
- A sheet with unsaved text closes without asking. A finished todo moves to Done without the slide.
- Handoff was skipped.

### Platform notes

- The APK comes from Build from GitHub in expo.dev, and it is not on the GitHub release.
- No migration and no Edge Function change.
- v2.0.1 replaces this APK.
