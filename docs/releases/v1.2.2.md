## Release notes

This text is a copy of the GitHub release.

This release adds the voice Inbox and accounts for more than one person. It also holds all of v1.2.1.

### Voice Inbox

- **Messages:** Record in the app, and the other person reads text from Groq Whisper. Inbox and Sent show the text, with Play audio and Retry.
- **Storage:** The audio is deleted after 7 days. The text stays.
- **Push:** A voice message sends a push at once, with no message text. Tapping the push opens Inbox.

### Accounts

- **Sign-up:** Anyone can create an account. Each account has separate data.
- **Voice access:** Only the admin ticks accounts on the Voice access screen. A ticked account and the admin can message each other. Ticked accounts cannot message each other.
- **Ulam limit:** Only the admin and ticked accounts get a Groq ulam. Other accounts see the bundled ulam.

### Platform notes

- The Android build is an APK from EAS Build. Install `my-app-1.2.2.apk` over the current app. It is not on the Play Store.
- This APK is the first build with v1.2.1. It adds Alarms, Ulam, Travel, the new look and the Vault changes. See the v1.2.1 notes.
- The APK has the same signing certificate as `my-app-1.1.0.apk`.
- The app now asks for microphone access for voice messages.
- The database changes and the `voice-transcribe`, `voice-cleanup`, `send-reminders` and `daily-ulam` Edge Functions are already live.

### Not tested yet

- Voice: a message sent both ways, a push on a locked phone, and Retry.
- A second account cannot read the first account's rows, in a live check of each module.
- No test file covers the Voice Inbox code, the Voice access rules or the instant push.
