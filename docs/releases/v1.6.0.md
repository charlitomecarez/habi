## Release notes

This text is a copy of the GitHub release.

v1.6.0 adds F1 and MotoGP in Sports, two new modules for Movies and YouTube, and Places near you in Travel. Each PR now runs a unit coverage gate and web tests. Install the v1.6.0 APK for Places near you.

### Sports

- **F1 and MotoGP:** two new chips in Sports. Each shows the next race in PHT, with a second line when it starts after midnight, the last result, the rounds and the standings.
- **Home:** a Show on Home switch for each series puts its next race and the last winner in the Games block.

### New modules

- **Movies:** the films in Philippine cinemas now and the next ones, from TMDB. A film opens its own screen with Watch trailer. The list updates each morning.
- **YouTube:** the new videos of the channels you follow, newest first, with a Channel filter. Add a channel by its link or @handle. Your channels are yours only.

### Travel

- **Places near you:** sights, food, parks and shopping within 10 km, with Open in Maps and Add to a trip. The app asks for your location only after Use my location, and your exact spot stays on the phone. Needs the v1.6.0 APK.
- **Place suggestions:** type 3 letters in the Place field of a trip item, and a tap on a suggestion fills Place and Map link.

### Tests and repo

- **Coverage gate:** CI fails when the unit tests cover less than 80% of the lines in `lib/` and the shared function code. Coverage went from 42% to 84%, with 605 tests.
- **E2E and Maestro:** each PR runs 5 Playwright tests on the web app as a test account. Five Maestro flows test the phone. See `docs/testing.md`.

### What moved

- Nothing moved. The YouTube feed gives no video length, so thumbnails show none. The design allows this.

### Platform notes

- The APK comes from Build from GitHub in expo.dev, and it is not on the GitHub release.
- The 4 migrations are live. `sports-sync`, `movies-sync`, `youtube-channel`, `youtube-sync`, `places-nearby` and `app-features` are deployed.
- On the web, Places near you and Weather's Use my location read the browser location.
- The E2E job runs on Ubuntu 24.04, because Playwright 1.56 has no Chromium for Ubuntu 26.04.
