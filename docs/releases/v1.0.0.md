## Release notes

This text is a copy of the GitHub release.

The first release of my-app. It runs on Android and on the web from one Expo codebase.

### Features

- **Sign in:** Google sign-in on Android and on the web. Only signed-in users can open the app.
- **Todos:** Todos have a due date, a priority and a repeat (daily, weekly or monthly). Reminders arrive as push notifications on Android. A daily email digest lists today's todos.
- **Vehicle:** Log the odometer and each service. The app shows which services are overdue or due soon. The Honda ADV 160 service intervals are built in.
- **Inventory:** Store items in nested locations (room, shelf, box), with photos and a quantity. Search finds any item. QR labels on boxes open their location.
- **Money:** Track accounts, expenses, income and transfers. Balances update from the transactions. Subscriptions show a monthly total in PHP and send a reminder before each renewal.
- **Vault:** Store passwords, encrypted on the device with Argon2id and XChaCha20-Poly1305. Supabase holds only the ciphertext. Fingerprint unlock works on Android, and copied passwords clear from the clipboard.
- **Design:** Light and dark themes, and a new app icon.

### Platform notes

- The Android build is an APK from EAS Build. Install it on the phone directly. It is not on the Play Store.
- The web app has no push notifications. Reminders show in the app and in the daily email digest.
