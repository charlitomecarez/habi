## Release notes

This text is a copy of the GitHub release.

This release adds statement import, three fixes and three small features.

### Fixes

- **Account balances:** Logging no longer changes account balances. Each balance is the number you type. This covers expenses, income, transfers, bills and auto-added subscriptions. No transaction is deleted.
- **Keyboard:** The focused field scrolls above the keyboard on Android.
- **Home photo:** The Home screen shows the Google photo.

### Statement import

- **Banks:** Money > Import statement reads GoTyme, GCash and MariBank PDFs.
- **Review:** Each row shows a tick, a name and a category. The app saves only the ticked rows.
- **Transfers and duplicates:** Own transfers pair up with their fee. Possible duplicates start unticked. A second import of the same rows saves nothing new.
- **Totals check:** A totals mismatch stops the import.
- **Privacy:** The `import-statement` Edge Function opens the PDF in memory and stores nothing. The PDF keys stay in the Edge Function secrets, not in the app.

### Money and profile

- **Expense names:** Past expense names show as chips in the transaction form. One tap fills the field, and typing narrows the chips.
- **Spending by category:** Previous and next month buttons show other months.
- **More photo:** The More screen shows the Google photo. It shows the first letter for email sign-in or when the image fails.

### Changes to v1.1.0 behaviour

- A debt payment no longer adds a Money transaction.
- Balances no longer update from the transactions. Type each balance by hand.

### Platform notes

- This release has no APK yet. `my-app-1.2.0.apk` comes later from Build from GitHub in expo.dev.
- The database changes and `import-statement` are already live. The installed v1.1.0 app still works.

### Not tested yet

- The keyboard fix has not run on a phone.
- The import screen and a signed-in import have not run in the app.
